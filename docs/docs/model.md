# 现行计算模型1.3.0

资料冻结2026年10月24日。金额亿元，销量及母猪万头，价格和成本元/公斤活重，股数亿股。现行字段以engine.js的PARAMS为准，共125项。

## 主线

必要产能成本14.9，加1000元权益资本乘10%回报再除120公斤，得到正常中枢15.733333。另设全年20元高位价，公司8000万头、120公斤、成本11.8、95%折算，利润747.84亿元，10倍PE外推129.541053元/股。

## 供需补充

有效供给比等于滞后母猪比乘MSY比乘全国重量比。直接MSY已包含相关生产阶段转换。总供给由国内及进口组成，再除需求趋势因子。常弹性逆需求先求零售价，再按绝对价差斜率转活猪价。历史振幅与成本中枢分别作为其他条件路线。

## 现金流

基础完全成本按首年与修复后成本直接形成路径。参照两者均11.8，因此各年11.8。折旧加回、必要维护、增长投资、营运资金和净融资分别计入。

FCFE = NI + D&A − 必要维护 − 增长投资 − ΔNWC + 净借款。

增长固定投资采用2000元/新增年销量头，提前一年付款，另计营运资金。终值维护等于D&A，正增长再投资按正利润×g/新增ROE扣除。FCFE用权益要求回报折现后直接得到股权，不重复扣净债。EV方法另作同范围净债及非控股桥接。

## 参照结果

需求路线2027均价14.355724，首年利润233.082071亿元。2029修复至15.5元后基础成本11.8，平量FCFE58.153279元/股，2031年9000万头61.226212元/股。终值g0、r10%、额外现金0，折现基准为2026年末。

实际未来折旧需资产年限及更新计划支持。纯折旧下降应同时调整完全成本与折旧加回，不能直接当作新增现金。完整来源、边界、公式和参数见仓库中的report-v3.md及audit.md。
