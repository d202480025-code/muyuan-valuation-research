# 1.3.0修订算法核查及报告对应

资料截止2026年10月24日，计算版本1.3.0。现行报告、PPT、讲稿和网站全部使用本版本，旧版估值不再用于当前材料。未公开的未来经营参数均为明确情景，非实际业绩预测。

## 修订内容

- 删除原有附加利润调整模块、三个相关参数及年度调整公式。它们不再参与任何价格、利润、终值、成长或估值计算。兼容导入仅识别并丢弃旧配置的废止字段，当前参数表没有这些字段。
- 年度完全成本直接按首年成本和修复后基础成本插值。参照两者均为11.8元/公斤，因此2027至2036各年完全成本均为11.8。
- 折旧摊销与必要维护分别列示，附录C及网页均可逐年核对。未来实际折旧需要资产年限、投产和更新明细，未编造确定下降幅度。
- 视频先完成可独立剪辑的26页猪周期行业篇；第27页起进入牧原案例，先完整完成同一假设下的价格、利润与10倍PE，再补充现金流方法。FCFF和FCFE的现金归属、折现率与净债调整在计算前专页解释。

## 主线结果

| 环节 | 演算 |
|---|---|
| 正常猪价中枢 | 14.9+1000×10%/120=15.733333元/kg |
| 另设高位年度价 | 20元/kg，相对中枢上浮27.1186%，该上浮为外生设定 |
| 销售公斤量 | 8000万头×120公斤=96亿公斤 |
| 收入 / 完全成本 | 1920亿元 / 1132.8亿元 |
| 演示归属利润 | (1920−1132.8)×95%=747.84亿元 |
| 10倍PE外推 | 747.84×10/57.72996144=129.541053元/股 |

20元是全年销售公斤加权价的情景，不能由边际成本公式单独推出。129.54是高位利润乘倍数的定价条件，未等同持续经营现金流价值。

## 折旧检查

另以零税费、无归属差异的同口径例子固定售价16元、96亿公斤、现金成本10.6元/kg、维护95亿元。单位折旧从1.2降至0.6，完全成本从11.8降到11.2，利润由403.2增至460.8亿元，折旧加回由115.2降至57.6亿元，FCFE均为423.4亿元。纯非现金折旧变化不会在同范围账户中凭空增加现金，真实维护、税务、付现成本及周转变化另计。

## 已完成的检查

1. 价格独立复写：63组设定、189条价格路线，1764次逐月价格比较、15876次数量及锚点比较，通过。三条价格路线没有受本次公司利润模块修订影响。
2. 当前网页原回归测试37组通过，相关预期值按现行模型重新计算。
3. 新增51项独立会计与公式检查：直接重写十年利润、固定成本、现金桥、折现与终值，并检查九千万头提前投资、主线PE、折旧账户及125项现行字段。
4. 修订估值复算脚本内121项独立恒等式及路径检查通过，输出完整年度结果、矩阵、联合情景、成长及8组最低资金需求。
5. PPT主讲49页、查阅附录6页，图表和表格保持可编辑，逐页口播写入备注。源报告的65项直接引用与逐行来源继续保留。

## 可复算文件

在仓库根目录执行：

```sh
node docs/tests/engine.test.js
node docs/tests/revised.test.js
node research/2026-10-24/materials/academic_work/price_assumptions.js
node research/2026-10-24/materials/academic_work/reproduce_valuation.js
```

两个计算脚本把结果写回同级JSON，元数据中的环境路径可能随机器变化，经济结果应在浮点容差内一致。版本、参数、文件哈希和测试日志随发布保留。

## 仍需明确的限制

真实全国月度MSY缺失，历史只有两个现代可比去化阶段。年度家庭需求弹性向月度活猪市场应用仍是先验，0.75绝对价差传导未由本次资料估计。必要边际成本14.9是参照地区调查后的判断，尚需全国同口径供给权重。95%为复合归属演示，维护65亿元加其他更新30亿元仍需财报勾稽。行业反馈、月内资金高峰、到期债务、再融资及增发稀释未完整联立。所有情景均未赋客观发生概率。
